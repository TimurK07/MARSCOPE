# MARSCOPE

**An interplanetary survival guide for future Mars explorers.**

MARSCOPE is an interactive, multi-layer map of Mars that combines open data from several NASA missions into one place, so a future astronaut or mission planner can click anywhere on the planet and see what it would take to survive there: water ice, terrain, landing safety, sunlight and other hazards.

Built for the **NASA Space Apps Challenge 2026**, challenge *Interplanetary Survival Guide: Martian Map*.

> 🚧 Work in progress: this project is being built during the hackathon.

## Features (planned)

- Interactive Mars basemap from NASA tiles
- Toggleable data layers (elevation, water ice, landing sites, slope, more)
- Click any point for a "survival breakdown" of that location
- Compare candidate sites side by side

## Tech stack

- Frontend: static web app (no backend required)
- Data preparation: Python scripts that turn NASA datasets into lightweight GeoJSON/JSON
